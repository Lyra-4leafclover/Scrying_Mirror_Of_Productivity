# ✧ Scrying Mirror of Productivity ✧

> An obsidian luxury productivity platform, focus chrono, multi-scale telemetry engine, and personal journal studio.

---

## ⚡ Core Features

- **Directives & Todo Matrix**: Instant task creation with priority tags, categories, and direct Pomodoro linking.
- **Luxury Focus Chrono**: Circular SVG pomodoro timer with focus/break presets, audio synthesizer chimes, and top HUD indicator.
- **Productivity Telemetry & Heatmap**: 100% authentic real-data tracking with 365-day contribution heatmaps, monthly calendars, weekly velocity, and 24-hour timelines.
- **Lecture Theater & Media Workspace**: Split-screen lecture player (YouTube & native HTML5 MP4/WebM) with live auto-saving lecture scratchpad and timestamp tools.
- **Philosophical Resonance**: Curated stoic and computer science reflections of the day.
- **Custom User Profiles & Isolation**: Switch or create independent profiles. Each user profile keeps its own isolated tasks, sessions, and journal logs.
- **Liquid Writings Studio**: Personal journal and article editor supporting inline image paste (`Ctrl+V`), local cover uploads, and reading modal.

---

## 🚀 Getting Started

### Local Setup
Simply open `index.html` in your browser, or start a local server:
```bash
# Using Python
python -m http.server 8000
```
Then visit `http://localhost:8000`.

### Deploy to Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Click **Deploy**. Zero configuration required!
